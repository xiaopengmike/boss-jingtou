# 精投助手（boss-jingtou）

BOSS 直聘**求职者侧**精投加速器（Chrome MV3 扩展，v0.1.0）。
定位不是"海投脚本"，而是：**采集职位 → 本地筛选分级 → 自动/人工队列 → 低速打招呼 → 台账追踪回复率**。

> ⚠️ **使用前必读（合规红线）**
> 1. 本工具违反 BOSS 直聘用户协议，存在限流、招呼静默失效、封号风险，**后果由使用者承担**。
> 2. 仅限**本人账号**自用，不对外分发；禁止多账号轮投（那是规避风控）。
> 3. 遇到验证码/滑块**自动停止并告警**，绝不绕过。
> 4. 默认从**小号**开始验证链路，主账号在灰度爬坡通过前不要接入。

## 安装

1. Chrome ≥ 102（MAIN world content script 需要）
2. `chrome://extensions` → 开发者模式 → 「加载已解压的扩展程序」→ 选本目录
3. 打开「设置」页核对：账号标签（小号/主账号）、自动化模式、关键词、招呼语模板

## 使用流程

```
① M0 取证（tools/recon.md，约 30 分钟，必做）
   └─ 校准 jt_rules 后关闭 pocMode
② 浏览 BOSS 搜索页/推荐页（正常翻页即可）
   扩展自动从接口响应里抓职位 → 本地筛选打分
   高置信（≥阈值）→ 自动入队；灰名单 → 面板勾选入队
③ 点「开始投递」（纯全自动模式可连这步都省）
   每条：开职位页 → 点「立即沟通」→ 进聊天页 → 发招呼语 → 校验落库
   条间 45–180s 随机，每 7 条休 8–15 分钟，10:00–19:00 之外不跑
④ popup 看进度 / 导出台账 CSV，用回复率反推问题
```

## 两种自动化模式

| 模式 | 行为 |
|---|---|
| `hybrid`（默认，推荐） | 高置信职位自动入队，灰名单等你在面板勾选；点「开始投递」后自动跑完 |
| `full` | 符合筛选即自动入队；勾选 autoStart 后新职位入队自动开跑，零人工 |

## 频控（核心安全层，勿轻易调快）

- 日上限：平台额度 100 条/天，但**灰度档位**决定实际上限（档0=5 → 档3=100），升档必须人工
- 100 条/天按默认节奏 ≈ 6.2 小时，刚好在 9 小时活跃时段内（余量 31%）
- 连续失败 3 次熔断暂停；疑似静默失效计入熔断；验证码即停

## 防静默失效

BOSS 触顶后招呼会"静默失效"（界面正常、对方收不到）。本扩展每条发送后都会在聊天区
轮询刚发的文本做**落库校验**：找不到 → 记 `suspected_silent` 并计入熔断。
台账里的 verified / suspected_silent 是判断真实送达率的唯一依据。

## 目录

```
manifest.json        扩展清单
background.js        SW：嗅探缓冲 / 队列状态机 / 频控 / tab 编排 / 台账
lib/                 constants(唯一真源) / storage / throttle(纯函数闸门) / ledger
content/             sniff-hook(MAIN) / sniff-relay / panel(面板) / greeter / chat-sender
popup/               仪表盘（进度/熔断/导出）
options/             设置页 + 导出下载通道
fixtures/            三个 mock 页（离线联调 greeter/chat-sender 的分支逻辑）
tools/recon.md       M0 取证手册（必做）
```

## 已知边界

- BOSS 页面/接口改版 → 在设置页改「规则 JSON」即可适配，不用改代码
- 做不到 100% 防封：合成点击的行为特征、账号画像、平台模型都不可控；
  本工具只能把"作死"降级成"试探"
